# CommandBridge Website

Static multi-page site for GitHub Pages at `commandbridge.ng`.

## Files

- `index.html`
- `about.html`
- `approach.html`
- `sectors.html`
- `contact.html`
- `styles.css`
- `CNAME`

## Publish on GitHub Pages

Upload these files to the root of the GitHub Pages repository and enable Pages from the default branch. The `CNAME` file points the site to `commandbridge.ng`.
